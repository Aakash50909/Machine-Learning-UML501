
# Machine Learning (UML501)

##  About This Repository

This repository contains my submission files, datasets, and practice notebooks for the **Machine Learning (UML501)** course. It documents my journey through data preprocessing, model selection, and performance evaluation.

##  Repository Structure

###  Assignments & Notebooks

| File Name | Description | Key Concepts |
| :--- | :--- | :--- |
| `Assignment_pandas_prac.ipynb` | Pandas Practice | Data Frames, Manipulation, Cleaning |
| `Assignment_1.ipynb` | Assignment 1 | Intro to ML, Data Exploration |
| `Assignment3.ipynb` | Assignment 3 | Feature Engineering, Model Training |
| `Assignment_4.ipynb` | Assignment 4 | Classification / Regression models |
| `Assignment-5.ipynb` | Assignment 5 | Model Evaluation, Hyperparameter Tuning |
| `Assignment-6.ipynb` | Assignment 6 | Advanced Algorithms (SVM/Trees) |
| `Assignment-7.ipynb` | Assignment 7 | Ensemble Methods / Neural Networks |
| `test` | Testing Script | Experimental code snippets |

###  Datasets Used

| Dataset | Description | Used In |
| :--- | :--- | :--- |
| `Boston_Housing.csv` | Housing price data for regression analysis | Regression Assignments |
| `Hitters.csv` | Major League Baseball data | Data Cleaning / Classification |

##  Tech Stack

  * **Language:** Python 3.x
  * **Libraries:**
      * `pandas` & `numpy` (Data Manipulation)
      * `matplotlib` & `seaborn` (Visualization)
      * `scikit-learn` (Model Implementation)

##  Getting Started

1.  **Clone the repo:**
    ```bash
    git clone https://github.com/Aakash50909/Machine-Learning-UML501.git
    ```
2.  **Navigate to the directory:**
    ```bash
    cd Machine-Learning-UML501
    ```
3.  **Launch Jupyter Notebook:**
    ```bash
    jupyter notebook
    ```
